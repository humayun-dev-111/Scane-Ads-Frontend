# Scane Ads Frontend

Frontend application for the Scane Ads platform, built with React, TypeScript, Vite, Tailwind CSS, and Redux Toolkit.

## Overview

Scane Ads Frontend provides:
- Public marketing pages and billboard browsing.
- Customer dashboard for campaign creation, campaign tracking, billing, and payments.
- Admin dashboard for screen management, campaign approval, scheduling, and payment monitoring.
- Map-based board discovery and geolocation-driven browsing.

## Tech Stack

- React 19 (RC)
- TypeScript
- Vite 6
- React Router 7
- Redux Toolkit + RTK Query
- Tailwind CSS 4
- Radix UI primitives
- Chart.js / ApexCharts
- Google Maps + Leaflet integrations

## Project Structure

```text

  common/                  Shared reusable UI pieces and helpers
  components/

```

## Getting Started

### Prerequisites

- Node.js 20+
- npm 10+

### Installation

```bash
npm install
```

### Environment Variables

Create a `.env` file in the project root:

```env
VITE_BASE_URL=https://your-api-domain.com
```

`VITE_BASE_URL` is required for all API requests and auth token refresh flows.

### Run Locally

```bash
npm run dev
```

App runs on Vite default port (typically `http://localhost:5173`).

## Available Scripts

- `npm run dev` - Start development server.
- `npm run build` - Type-check and build production bundle.
- `npm run preview` - Preview production build locally.

## Authentication Notes

- Auth state is stored in Redux.
- API requests include token from Redux state.
- On `401`, the app attempts refresh via `POST /auth/refresh-token` using `VITE_BASE_URL`.
- Session uses `credentials: include` to support cookie-based refresh.

## Build and Deployment

- Production build output is generated by Vite.
- `vercel.json` is included for Vercel deployment configuration.
